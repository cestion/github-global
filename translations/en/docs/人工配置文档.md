# GitHub Global - Manual Configuration Guide

This document describes the manual configuration steps that need to be completed before starting the project.

---

## 1. Create GitHub App

### 1.1 Access GitHub Settings

1. Log in to GitHub
2. Go to **Settings** > **Developer settings** > **GitHub Apps**
3. Click **New GitHub App**

### 1.2 Fill in Basic Information

| Field | Value |
|-------|-------|
| **GitHub App name** | `GitHub Global` (or your custom name) |
| **Homepage URL** | `http://localhost:3000` (development) or your domain |
| **Callback URL** | `http://localhost:3000/api/auth/callback/github` |
| **Setup URL** | `http://localhost:3000/dashboard` (optional) |
| **Webhook URL** | `http://localhost:3000/api/webhooks/github` (optional) |
| **Webhook Secret** | Generate a random secret (you can use `openssl rand -hex 32`) |

### 1.3 Configure Permissions

#### Repository Permissions

| Permission | Level | Description |
|------------|-------|-------------|
| **Contents** | Read & Write | Read repository files, create translation files, create branches |
| **Metadata** | Read | Read basic repository information |
| **Pull requests** | Read & Write | Create and manage Pull Requests |

#### Account Permissions

| Permission | Level | Description |
|------------|-------|-------------|
| **Email addresses** | Read | Get user email for commit authorship |

### 1.4 Subscribe to Events (Optional)

If you need automatic sync functionality, subscribe to the following events:

- `push` - Detect code changes
- `installation` - Listen for App installation/uninstallation
- `installation_repositories` - Listen for repository addition/removal

### 1.5 Save Configuration

1. Click **Create GitHub App**
2. After successful creation, record the following information:
   - **App ID**
   - **Client ID**
   - **Client Secret** (click Generate a new client secret)
3. Generate and download **Private Key** (click Generate a private key)

## 2. Configure OpenRouter API Key

### 2.1 Register OpenRouter Account

1. Visit [OpenRouter](https://openrouter.ai/)
2. Register and log in to your account

### 2.2 Get API Key

1. Visit [API Keys page](https://openrouter.ai/keys)
2. Click **Create Key**
3. Copy the generated API Key (format: `sk-or-v1-xxxxxxxx`)

### 2.3 Add Credit (Optional)

If using platform-hosted mode, you need to add credit to your OpenRouter account.

## 3. Configure MySQL Database

### 3.1 Install MySQL

#### Windows

1. Download [MySQL Installer](https://dev.mysql.com/downloads/installer/)
2. Install MySQL Server 8.0
3. Set root password

#### macOS

```bash
brew install mysql@8.0
brew services start mysql@8.0
```

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
```

### 3.2 Create Database

```sql
-- Log in to MySQL
mysql -u root -p

-- Create database
CREATE DATABASE github_global CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Create user (optional)
CREATE USER 'github_global'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON github_global.* TO 'github_global'@'localhost';
FLUSH PRIVILEGES;
```

## 4. Configure Environment Variables

### 4.1 Copy Environment Variable Template

```bash
cp .env.example .env
```

### 4.2 Fill in Environment Variables

Edit the `.env` file and add the following configuration:

```bash
# Database configuration
DATABASE_URL="mysql://github_global:your_password@localhost:3306/github_global"

# NextAuth configuration
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-nextauth-secret-key"  # Generate using openssl rand -base64 32

# GitHub App configuration
GITHUB_APP_ID="123456"  # Get from GitHub App page
GITHUB_APP_CLIENT_ID="Iv1.xxxxxxxxxx"  # Get from GitHub App page
GITHUB_APP_CLIENT_SECRET="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # Get from GitHub App page
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEpAIBAAKCAQEA...\n-----END RSA PRIVATE KEY-----"  # Replace \n with actual newlines from downloaded private key
GITHUB_WEBHOOK_SECRET="your-webhook-secret"  # Secret set when creating GitHub App

# Encryption key (32 bytes hex)
ENCRYPTION_KEY="0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"  # Generate using openssl rand -hex 32

# Platform-hosted OpenRouter API Key
PLATFORM_OPENROUTER_API_KEY="sk-or-v1-xxxxxxxxxxxxxxxx"  # Get from OpenRouter
```

### 4.3 Generate Keys

#### NEXTAUTH_SECRET

```bash
openssl rand -base64 32
```

#### ENCRYPTION_KEY

```bash
openssl rand -hex 32
```

#### GITHUB_WEBHOOK_SECRET

```bash
openssl rand -hex 32
```

### 4.4 Handle GitHub Private Key

The GitHub private key is multi-line text and requires special handling:

**Method 1: Use \n escaping**

```bash
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEpAIBAAKCAQEA...\n-----END RSA PRIVATE KEY-----"
```

**Method 2: Use environment variable file (recommended)**

Save the private key as a `private-key.pem` file and read it in the code.

## FAQ

### Q1: GitHub Private Key Format Error

**Problem**: Error `Error: Invalid PEM formatted message` on startup

**Solution**:
- Make sure the private key includes complete `-----BEGIN RSA PRIVATE KEY-----` and `-----END RSA PRIVATE KEY-----`
- Make sure newlines are correct (use `\n` or actual newlines)
- You can use online tools to verify PEM format

### Q2: Database Connection Failed

**Problem**: Error `Can't reach database server` on startup

**Solution**:
- Check if MySQL service is running
- Check if `DATABASE_URL` configuration is correct
- Check database user permissions

### Q3: OpenRouter API Key Invalid

**Problem**: Error `401 Unauthorized` during translation

**Solution**:
- Check if API Key is copied correctly
- Check if OpenRouter account has balance
- Check if API Key is activated

## Security Recommendations

1. **Don't commit .env file to Git**
   - Already configured in `.gitignore`
   - Use `.env.example` as template

2. **Rotate keys regularly**
   - NEXTAUTH_SECRET
   - ENCRYPTION_KEY
   - GITHUB_WEBHOOK_SECRET

3. **Limit GitHub App permissions**
   - Only grant necessary permissions
   - Regularly review installed repositories

4. **Protect OpenRouter API Key**
   - Don't expose in client-side code
   - Use environment variables for storage
   - Regularly check usage
