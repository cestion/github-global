# GitHub Global - Quick Start Guide

This document explains how to quickly start the GitHub Global project.

---

## Prerequisites

Before starting, please ensure you have completed:

1. ✅ All configuration steps in [Manual Configuration Document](./人工配置文档.md)
2. ✅ Installed Node.js 20+ and npm 10+
3. ✅ Installed MySQL 8.0+
4. ✅ Configured the `.env` file

---

## Method 1: Local Development Startup

### 1. Install Dependencies

```bash
npm install
```

### 2. Generate Prisma Client

```bash
npm run db:generate
```

### 3. Initialize Database

#### Method A: Using Prisma Migrate (Recommended)

```bash
npm run db:migrate
```

This will create database migration files and apply them to the database.

#### Method B: Push Schema Directly

```bash
npm run db:push
```

This will directly synchronize the Prisma Schema to the database (suitable for development environment).

### 4. Start Development Server

```bash
npm run dev
```

### 5. Access the Application

Open your browser and visit: http://localhost:3000

---

## Method 2: Docker Deployment

### 1. Configure Environment Variables

Ensure the `.env` file is properly configured.

### 2. Start Docker Compose

```bash
docker-compose up -d
```

This will start two containers:
- `app`: Next.js application
- `db`: MySQL database

### 3. Run Database Migration

```bash
docker-compose exec app npx prisma migrate deploy
```

### 4. View Logs

```bash
docker-compose logs -f app
```

### 5. Access the Application

Open your browser and visit: http://localhost:3000

### 6. Stop Services

```bash
docker-compose down
```

### 7. Clean Up Data (Optional)

```bash
docker-compose down -v  # Delete data volumes
```

## Usage Flow

### 1. Login to System

1. Visit http://localhost:3000
2. Click "Login with GitHub"
3. Authorize the GitHub App

### 2. Import Repository

Import repository using API:

```bash
curl -X POST http://localhost:3000/api/repos \
  -H "Content-Type: application/json" \
  -d '{
    "repoUrl": "https://github.com/username/repo-name"
  }'
```

### 3. Configure Translation

Update repository configuration:

```bash
curl -X PUT http://localhost:3000/api/repos/{repo_id}/config \
  -H "Content-Type: application/json" \
  -d '{
    "baseLanguage": "zh-CN",
    "targetLanguages": ["en", "ja", "ko"]
  }'
```

### 4. Create Translation Task

```bash
curl -X POST http://localhost:3000/api/translations \
  -H "Content-Type: application/json" \
  -d '{
    "repositoryId": "{repo_id}",
    "targetLanguages": ["en", "ja"],
    "type": "FULL"
  }'
```

### 5. View Translation Progress

Use SSE to get progress in real-time:

```javascript
const eventSource = new EventSource('/api/translations/{task_id}/progress');

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Progress:', data.progress);
};
```

### 6. View Pull Request

After translation is complete, a Pull Request will be automatically created. You can view and merge it in the GitHub repository.

## Troubleshooting

### Problem 1: Port Already in Use

**Error**: `Error: listen EADDRINUSE: address already in use :::3000`

**Solution**:

```bash
# Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# macOS/Linux
lsof -ti:3000 | xargs kill -9
```

### Problem 2: Database Connection Failed

**Error**: `Can't reach database server at localhost:3306`

**Solution**:

1. Check if MySQL is running
2. Check the `DATABASE_URL` configuration in `.env`
3. Test database connection:

```bash
mysql -h localhost -u github_global -p
```

### Problem 3: Prisma Client Not Generated

**Error**: `Cannot find module '@prisma/client'`

**Solution**:

```bash
npm run db:generate
```

### Problem 4: GitHub App Authentication Failed

**Error**: `Error: Invalid GitHub App credentials`

**Solution**:

1. Check GitHub App configuration in `.env`
2. Ensure the private key format is correct
3. Check if App ID and Client ID match

### Problem 5: OpenRouter API Call Failed

**Error**: `401 Unauthorized` or `429 Rate Limit`

**Solution**:

1. Check if API Key is correct
2. Check OpenRouter account balance
3. Check if API rate limit is exceeded

## Production Deployment Suggestions

### 1. Environment Variables

- Update `NEXTAUTH_URL` with production domain
- Use strong passwords and keys
- Do not hardcode sensitive information in code

### 2. Database

- Use cloud database services (e.g., AWS RDS, Alibaba Cloud RDS)
- Configure database backups
- Enable SSL connections

### 3. Reverse Proxy

Use Nginx or Caddy as reverse proxy:

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 4. HTTPS

Use Let's Encrypt to configure SSL certificates:

```bash
certbot --nginx -d your-domain.com
```

### 5. Monitoring and Logging

- Configure log collection (e.g., Winston, Pino)
- Configure error monitoring (e.g., Sentry)
- Configure performance monitoring (e.g., New Relic)
