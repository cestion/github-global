```
github-global/

└── ...
```

### 2.2 Configure Environment Variables

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Edit the `.env` file:

```env
# Database configuration
DATABASE_URL="mysql://root:your_password@localhost:3306/github_global"

GITHUB_APP_CLIENT_ID="your_client_id"
```

## 6. FAQ

### Q1: How to generate NEXTAUTH_SECRET?

**Answer**: Just input any string with at least 32 characters, for example:

```
NEXTAUTH_SECRET="my-super-secret-key-for-nextauth-session-management-2024"
```

### Q2: Where to place the private key file?

**Answer**: Place it in the project root directory, at the same level as `package.json`:

```
github-global/
├── private-key.pem  <-- Here
├── package.json
├── src/
└── ...
```

### Q3: How to get GitHub App private key?

**Answer**:
1. Go to GitHub App settings page
2. Scroll to "Private keys" section
3. Click "Generate a private key"
4. Download the `.pem` file
5. Rename to `private-key.pem` and place in project root directory

### Q4: Database connection failed?

**Answer**: Check if MySQL is running and confirm `DATABASE_URL` configuration is correct:

```bash
# Test MySQL connection
mysql -u root -p

# Create database
CREATE DATABASE github_global;
```

### Q5: Don't need to encrypt sensitive data?

**Answer**: For quick development, we use simplified Base64 encoding. For production, it is recommended to use proper encryption (AES-256).
