# GitHub Global - 手動設定ドキュメント

本文書は、プロジェクトを起動する前に手動で完了する必要がある設定手順について説明します。

---

## 1. GitHub App の作成

### 1.1 GitHub 設定へのアクセス

1. GitHub にログイン
2. **Settings** > **Developer settings** > **GitHub Apps** にアクセス
3. **New GitHub App** をクリック

### 1.2 基本情報の入力

| フィールド | 値 |
|------|-----|
| **GitHub App name** | `GitHub Global` (またはカスタム名) |
| **Homepage URL** | `http://localhost:3000` (開発環境) またはあなたのドメイン |
| **Callback URL** | `http://localhost:3000/api/auth/callback/github` |
| **Setup URL** | `http://localhost:3000/dashboard` (任意) |
| **Webhook URL** | `http://localhost:3000/api/webhooks/github` (任意) |
| **Webhook Secret** | ランダムに生成したシークレット (`openssl rand -hex 32` を使用可能) |

### 1.3 権限の設定

#### Repository Permissions（リポジトリ権限）

| 権限 | レベル | 説明 |
|------|------|------|
| **Contents** | Read & Write | リポジトリファイルの読み取り、翻訳ファイルの作成、ブランチの作成 |
| **Metadata** | Read | リポジトリの基本情報の読み取り |
| **Pull requests** | Read & Write | Pull Request の作成と管理 |

#### Account Permissions（アカウント権限）

| 権限 | レベル | 説明 |
|------|------|------|
| **Email addresses** | Read | commit 送信用のユーザーメールの取得 |

### 1.4 イベントのサブスクリプション（任意）

自動同期機能が必要な場合は、以下のイベントをサブスクライブ：

- `push` - コード変更の検出
- `installation` - App のインストール/アンインストールを監視
- `installation_repositories` - リポジトリの追加/削除を監視

### 1.5 設定の保存

1. **Create GitHub App** をクリック
2. 作成成功后、以下の情報を記録：
   - **App ID**
   - **Client ID**
   - **Client Secret**（**Generate a new client secret** をクリック）
3. **Private Key** を生成してダウンロード（**Generate a private key** をクリック）

## 2. OpenRouter API Key の設定

### 2.1 OpenRouter アカウント登録

1. [OpenRouter](https://openrouter.ai/) にアクセス
2. アカウントを登録してログイン

### 2.2 API Key の取得

1. [API Keys ページ](https://openrouter.ai/keys) にアクセス
2. **Create Key** をクリック
3. 生成された API Key をコピー（形式: `sk-or-v1-xxxxxxxx`）

### 2.3 クレジット充值（任意）

プラットフォームホストモードを使用する場合、OpenRouter アカウントにクレジットを充值する必要があります。

---

## 3. MySQL データベースの設定

### 3.1 MySQL のインストール

#### Windows

1. [MySQL Installer](https://dev.mysql.com/downloads/installer/) をダウンロード
2. MySQL Server 8.0 をインストール
3. root パスワードを設定

#### macOS

```bash
brew install mysql@8.0
brew services start mysql@8.0
```

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
```

### 3.2 データベースの作成

```sql
-- MySQL にログイン
mysql -u root -p

-- データベースの作成
CREATE DATABASE github_global CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- ユーザーの作成（任意）
CREATE USER 'github_global'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON github_global.* TO 'github_global'@'localhost';
FLUSH PRIVILEGES;
```

## 4. 環境変数の設定

### 4.1 環境変数テンプレートのコピー

```bash
cp .env.example .env
```

### 4.2 環境変数の入力

`.env` ファイルを編集し、以下の設定を入力：

```bash
# データベース設定
DATABASE_URL="mysql://github_global:your_password@localhost:3306/github_global"

# NextAuth 設定
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-nextauth-secret-key"  # openssl rand -base64 32 で生成

# GitHub App 設定
GITHUB_APP_ID="123456"  # GitHub App ページから取得
GITHUB_APP_CLIENT_ID="Iv1.xxxxxxxxxx"  # GitHub App ページから取得
GITHUB_APP_CLIENT_SECRET="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # GitHub App ページから取得
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEpAIBAAKCAQEA...\n-----END RSA PRIVATE KEY-----"  # ダウンロードした秘密鍵の \n を実際の改行に置換
GITHUB_WEBHOOK_SECRET="your-webhook-secret"  # GitHub App 作成時に設定したシークレット

# 暗号化キー (32 bytes hex)
ENCRYPTION_KEY="0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"  # openssl rand -hex 32 で生成

# プラットフォームホストの OpenRouter API Key
PLATFORM_OPENROUTER_API_KEY="sk-or-v1-xxxxxxxxxxxxxxxx"  # OpenRouter から取得
```

### 4.3 キーの生成

#### NEXTAUTH_SECRET

```bash
openssl rand -base64 32
```

#### ENCRYPTION_KEY

```bash
openssl rand -hex 32
```

#### GITHUB_WEBHOOK_SECRET

```bash
openssl rand -hex 32
```

### 4.4 GitHub Private Key の処理

GitHub 秘密鍵は複数行のテキストなので、特別な処理が必要です：

**方法 1: \n エスケープを使用**

```bash
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEpAIBAAKCAQEA...\n-----END RSA PRIVATE KEY-----"
```

**方法 2: 環境変数ファイルを使用（推奨）**

秘密鍵を `private-key.pem` ファイルとして保存し、コード内で読み取ります。

## 5. GitHub App のインストール

### 5.1 個人アカウントへのインストール

1. あなたの GitHub App ページにアクセス
2. **Install App** をクリック
3. **Only select repositories** または **All repositories** を選択
4. **Install** をクリック

### 5.2 Installation ID の取得

インストール完了後、URL に Installation ID が含まれます：

```
https://github.com/settings/installations/12345678
```

ここの `12345678` が Installation ID です（自動的にデータベースに保存されるため、手動設定は不要です）。

## よくある質問

### Q1: GitHub Private Key フォーマットエラー

**問題**: 起動時にエラー `Error: Invalid PEM formatted message` が発生

**解決策**: 
- 秘密鍵に完全な `-----BEGIN RSA PRIVATE KEY-----` と `-----END RSA PRIVATE KEY-----` が含まれていることを確認
- 改行符が正しいことを確認（`\n` または実際の改行を使用）
- オンライン工具で PEM フォーマットを検証可能

### Q2: データベース接続失敗

**問題**: 起動時にエラー `Can't reach database server` が発生

**解決策**:
- MySQL サービスが起動していることを確認
- `DATABASE_URL` 設定が正しいことを確認
- データベースユーザーの権限を確認

### Q3: OpenRouter API Key が無効

**問題**: 翻訳時にエラー `401 Unauthorized` が発生

**解決策**:
- API Key が正しくコピーされていることを確認
- OpenRouter アカウントにクレジットがあることを確認
- API Key が有効化されていることを確認

## セキュリティの推奨事項

1. **.env ファイルを Git にコミットしない**
   - `.gitignore` で設定済み
   - `.env.example` をテンプレートとして使用

2. **キーの定期変更**
   - NEXTAUTH_SECRET
   - ENCRYPTION_KEY
   - GITHUB_WEBHOOK_SECRET

3. **GitHub App 権限の制限**
   - 必要な権限のみ付与
   - インストール済みリポジトリを定期的にレビュー

4. **OpenRouter API Key の保護**
   - クライアントコードで公開しない
   - 環境変数に保存
   - 使用量を定期的にチェック
