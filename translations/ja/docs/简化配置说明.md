# GitHub Global - 簡略化された設定ガイド

> このドキュメントでは、openssl コマンドを使用しない簡略化された設定手順を提供します

---

## 1. GitHub App の作成

### 1.1 GitHub 設定へのアクセス

1. GitHub にログイン
2. **Settings** > **Developer settings** > **GitHub Apps** にアクセス
3. **New GitHub App** をクリック

### 1.2 基本情報の入力

| フィールド | 値 |
|------|-----|
| **GitHub App name** | `GitHub Global` |
| **Homepage URL** | `http://localhost:3000` |
| **Callback URL** | `http://localhost:3000/api/auth/callback/github` |
| **Webhook** | 「Active」のチェックを外す（当面は不需要） |

### 1.3 権限の設定

#### Repository Permissions

- **Contents**: Read & Write
- **Metadata**: Read
- **Pull requests**: Read & Write

#### Account Permissions

- **Email addresses**: Read

### 1.4 設定の保存

1. **Create GitHub App** をクリック
2. 以下の情報を記録：
   - **App ID**
   - **Client ID**
3. **Generate a new client secret** をクリックし、**Client Secret** を記録
4. **Generate a private key** をクリックし、秘密鍵ファイル（.pem 形式）をダウンロード

---

## 2. プロジェクトの設定

### 2.1 秘密鍵ファイルのコピー

ダウンロードした秘密鍵ファイルの名前を `private-key.pem` に変更し、プロジェクトのルートディレクトリに置きます：

```
github-global/
├── private-key.pem  <-- ここに配置
├── src/
├── package.json
└── ...
```

### 2.2 環境変数の設定

`.env.example` を `.env` にコピー：

```bash
cp .env.example .env
```

`.env` ファイルを編集：

```env
# データベース設定
DATABASE_URL="mysql://root:あなたのパスワード@localhost:3306/github_global"

# NextAuth 設定
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="any-random-string-at-least-32-characters-long-for-session"

# GitHub App 設定
GITHUB_APP_ID="あなたのApp ID"
GITHUB_APP_CLIENT_ID="あなたのClient ID"
GITHUB_APP_CLIENT_SECRET="あなたのClient Secret"
GITHUB_APP_PRIVATE_KEY_PATH="./private-key.pem"

# OpenRouter API Key（オプション、プラットフォームホストモード用）
PLATFORM_OPENROUTER_API_KEY="sk-or-v1-あなたのkey"
```

**説明**：
- `NEXTAUTH_SECRET`: 32文字以上の文字列を適当に入力してください
- `GITHUB_WEBHOOK_SECRET`: 入力不要（削除済み）
- `ENCRYPTION_KEY` は不要になりました（Base64 エンコードに簡略化済み）

## 6. よくある問題

### Q1: NEXTAUTH_SECRET の生成方法は？

**答**: 32文字以上の文字列を適当に入力してください、例：

```
NEXTAUTH_SECRET="my-super-secret-key-for-nextauth-session-management-2024"
```

### Q2: 秘密鍵ファイルはどこに置けばよいですか？

**答**: プロジェクトのルートディレクトリ、`package.json` と同じ階層に置きます：

```
github-global/
├── private-key.pem  <-- ここ
├── package.json
├── src/
└── ...
```

### Q3: GitHub App の秘密鍵の取得方法は？

**答**: 
1. GitHub App 設定ページで
2. 「Private keys」セクションまでスクロール
3. 「Generate a private key」をクリック
4. `.pem` ファイルをダウンロード
5. `private-key.pem` に名前を変更し、プロジェクトのルートディレクトリに保存

### Q4: データベース接続に失敗します

**答**: MySQL が起動しているか確認し、`DATABASE_URL` の設定が正しいか確認：

```bash
# MySQL 接続テスト
mysql -u root -p

# データベースの作成
CREATE DATABASE github_global;
```

### Q5: 機密データの暗号化存储は不要ですか？

**答**: 快速開発のために、簡略化された Base64 エンコードを使用しています。本番環境では本格的な暗号化（AES-256）の使用を推奨します。
