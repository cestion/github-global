# GitHub Global - 要件定義書 (PRD)

> バージョン：v1.0.0
> 日付：2026-01-20
> 作成者：魚皮

## 1. プロジェクト概要

### 1.1 プロジェクト名

**GitHub Global** (github-global)

### 1.2 プロジェクト定位

一連の GitHub リポジトリ多言語翻訳 SaaS プラットフォーム。オープンソースプロジェクトの作者がドキュメントを自動的に複数の言語に翻訳し、国際的な影響力を拡大をサポートします。

### 1.3 ターゲットユーザー

- オープンソースプロジェクトメンテナー
- 技術ブログ/チュートリアル作者
- プロジェクトの国際化を希望する開発者
- 中国プロジェクト海外展開ニーズのある人

### 1.4 コアバリュー提案

> **「ゼロ設定、ワンクリック翻訳で、GitHub プロジェクトを世界へ」**

既存ソリューション（Azure/co-op-translator など）と比較した当プロジェクトの独自の価値：

- ✅ **即座に使用可能** - GitHub Actions の設定不要、ローカル環境不要
- ✅ **SaaS サービス** - 完成されたウェブサービスを提供し、オンラインで操作可能
- ✅ **マルチモデルサポート** - OpenRouter 経由で 다양한 AI モデルを一括接入
- ✅ **スマート同期** - GitHub コミット変更を自動検出、増分翻訳
- ✅ **ビジュアル設定** - インターフェースで翻訳範囲を選択でき、手動での設定ファイル作成が不要

---

## 2. プロダクト形態

### 2.1 主要形態

**オンラインプラットフォーム / SaaS サービス**

### 2.2 サービスモード

| モード | 説明 |
| ---------------------- | ---------------------------------------------------------- |
| **ホスティングモード** | プラットフォームが AI 翻訳サービスを提供し、ユーザーが直接使用（有料またはクォータ制限の可能性あり） |
| **BYOK モード** | ユーザーが自分の OpenRouter API Key を設定し、プラットフォームは翻訳プロセスのみを提供 |

### 2.3 アクセス方法

- Web ウェブアプリケーション
- 将来的に GitHub App 統合のサポートを検討

#### 3.2.2 翻訳範囲設定

**ビジュアル設定インターフェース**：

- リポジトリのファイルツリー構造を表示
- チェックボックスで翻訳するディレクトリ/ファイルを選択
- 全選択/選択解除をサポート
- Markdown ファイルを自動認識

**設定ファイル同期**：

- ビジュアル選択の結果は自動的に `.github-global-ignore` ファイルに同期
- 設定ファイルを変更すると、インターフェースが自動的に更新

**`.github-global-ignore` ファイル形式**：

```gitignore
# node_modules を無視
node_modules/

# 特定のファイルを無視
CHANGELOG.md
CONTRIBUTING.md

# 特定のディレクトリを無視
docs/internal/
.vuepress/
```

#### 3.2.3 翻訳保存構造

翻訳后的文件保存在 `translations/`目录下，按语言分目录：

```
repository/
├── README.md                    # ベース言語（中国語）
├── docs/
│   └── guide.md
├── translations/
│   ├── en/                      # 英語翻訳
│   │   ├── README.md
│   │   └── docs/
│   │       └── guide.md
│   ├── ja/                      # 日本語翻訳
│   │   ├── README.md
│   │   └── docs/
│   │       └── guide.md
│   └── ...
└── .github-global-ignore        # 無視設定ファイル
```

#### 3.2.4 多言語リンク生成

AI が README ファイル構造を分析した後、適切な位置に多言語切り替えリンクを挿入：

**生成形式例**：

```markdown
## 🌐 多言語バージョン / Translations

[English](./translations/en/README.md) | [日本語](./translations/ja/README.md) | [한국어](./translations/ko/README.md)

---
```

**挿入位置戦略**：

1. 既存の言語切り替えエリアがある場合は、そのエリアを更新
2. プロジェクトタイトル後の紹介エリアがある場合は、紹介の後に挿入
3. 目次（TOC）がある場合は、目次の前に挿入
4. フォールバック：ファイルの先頭に挿入

## 8. リスクと対応

| リスク | 影響 | 対応戦略 |
| ------------------- | ---------------- | ---------------------------------- |
| OpenRouter API レート制限 | 翻訳速度が遅い | ユーザーが自分の API Key を持てるサポート；リクエストキューを実装 |
| GitHub API レート制限 | リポジトリ情報を取得できない | API レスポンスをキャッシュ；リクエスト頻度を最適化 |
| AI 翻訳品質が不安定 | ユーザー体験が悪い | 翻訳プレビューを提供；手動編集をサポート |
| 大容量ファイルの翻訳タイムアウト | タスクが失敗 | チャンク分割翻訳；非同期処理 |
